# Data Generation Scripts

## convertCsvToJson.js

Automatically converts `summary_by_activity.csv` from the C++ analysis into `processedMotionData.json` for the Next.js frontend.

### What it does

1. **Reads** `../../../summary_by_activity.csv` (generated by the C++ program)
2. **Parses** CSV data with headers
3. **Normalizes** metrics:
   - `avgPeakAcceleration` → `inferredAmplitude` (0.1 to 1.0 range)
   - `avgPeakGyro` → `inferredCadence` (0.3 to 1.5 range)
   - `avgSmoothness` → smoothness factor
4. **Applies** activity-specific rules:
   - Walking types: knee lift and downward step bias
   - Static activities: reduced motion and posture-specific values
5. **Outputs** to `../public/processedMotionData.json`

### Usage

```bash
cd web
npm run generate:data
```

Or directly:
```bash
node scripts/convertCsvToJson.js
```

### Workflow

After analyzing with the C++ program:

```bash
# 1. Run C++ analysis
./har_rehab_cpp.exe

# 2. Navigate to web directory
cd web

# 3. Auto-generate frontend data
npm run generate:data

# 4. Refresh browser to load new data
```

All done—no manual JSON editing needed!
